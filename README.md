# OPC UA Client • Промышленная диспетчеризация

Современный веб-клиент и HMI-интерфейс для мониторинга технологических процессов, диспетчеризации ПЛК и взаимодействия с серверами OPC UA.

## Стек технологий
- **Framework**: Next.js 16 (App Router), React 19
- **Styling**: Tailwind CSS (Utility-first)
- **Icons**: Phosphor Icons (Light / Thin)
- **Typography**: Inter / Outfit / JetBrains Mono

## Основной функционал
- **Категории промышленного оборудования**: ПЛК (Siemens, Schneider, Овен, Beckhoff), сетевые шлюзы Modbus/Profinet, SCADA-серверы, цифровые смарт-устройства.
- **Диспетчеризация и управление подключениями**:
  - Быстрый автопоиск устройств в подсети (LDS / mDNS) с пингом и обнаружением портов 4840.
  - Ручная параметризация с выбором политик безопасности (Basic256Sha256, Aes128, Sign & Encrypt).
  - Интерактивный боковой дровер с живой визуальной связкой (Selection Ring).
- **Адресное пространство и сессии (Address Space)**:
  - Иерархическое дерево узлов (Root, Objects, Server, Variables).
  - Таблица телеметрии и инспектор атрибутов в реальном времени.
- **Журнал аварий и событий (IEC 62541-9 A&C)**:
  - Ранжирование аварий по критичности.
  - Минималистичная таблица с фильтрацией и квитированием.
- **Сертификаты и безопасность**:
  - Управление доверенными сертификатами x509, статусными плашками и списками отзыва (CRL).

## Запуск проекта

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера
npm run dev

# Сборка production-бандла
npm run build
```

Открыть [http://localhost:3000](http://localhost:3000) в браузере.
